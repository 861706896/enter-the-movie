# 进入电影 / ENTER THE MOVIE

一个基于 Three.js 的沉浸式空间影院网站，以第一人称视角探索比奇堡大世界。

## 在线体验

👉 [点击访问网站](https://861706896.github.io/enter-the-movie/)

## 功能特色

### 影厅大厅
- 🎬 **第一人称自由移动**：WASD 移动，鼠标控制视角
- 🎫 **自助选片机**：点击选片，银幕播放影片动画
- 🖼️ **电影海报墙**：三面电影海报可点击查看详情
- 🪑 **座位与红毯**：影厅座位分布合理，中央红毯通道

### 三种进入模式
1. **👁 观察者模式** — 自由漫步，点击热点触发事件
2. **👤 介入者模式** — 移动光点，与 NPC 对话互动，完成任务
3. **🎭 化身 NPC 模式** — 创建专属角色，点击任意 NPC 化身成该角色

### 三个世界场景
- **蟹堡王 (Krusty Krab)** — 海绵宝宝的工作场所，有柜台、烤架、船舵桌
- **水母田 (Jellyfish Fields)** — 派大星的石头、章鱼哥的画架、发光水母
- **痞老板实验室 (Plankton's Lab)** — 能量核心、机械臂、凯伦系统

### 交互系统
- 🖱️ **F 键交互**：靠近可交互物品按 F 键触发
- 🎒 **道具收集**：锅铲、捕水母网、蟹黄堡秘方等
- 💬 **NPC 对话**：点击角色进行对话
- 🎭 **角色化身**：化身任意角色，以第一人称自由探索

## 操作说明

| 按键 | 功能 |
|------|------|
| **W/A/S/D** | 移动 |
| **鼠标** | 控制视角（点击画面锁定指针） |
| **F** | 交互 / 化身角色 |
| **ESC** | 退出化身 / 退出指针锁定 |
| **Q/E** | 上升 / 下降 |
| **Shift** | 加速跑 |

## 技术栈

- **Three.js** — 3D 渲染引擎
- **Pointer Lock API** — 第一人称视角控制
- **HTML5 Canvas** — 程序化纹理生成
- **原生 JavaScript** — 无框架依赖
